# Missão Resgate

Jogo de labirinto: você é o quadradinho amarelo e precisa salvar a pessoa que pede socorro, levando ela até a casa verde, sem encostar no fogo.

- 3 mundos com 5 fases cada (Noite, Vulcão e Caverna de Gelo)
- Estrela mágica: 4 segundos invencível e os foguinhos fogem
- 3 corações; GAME OVER volta pro Mundo 1
- Modo de lado para tablet e celular
- Tutorial no começo (botão **?** abre de novo)
- Painel de admin (botão ⚙): pular de fase, vidas infinitas, fogo parado e estrela na hora

## Como jogar

Abra o `index.html` no navegador. Controles: setinhas na tela, deslizar o dedo no tabuleiro ou setas do teclado.
